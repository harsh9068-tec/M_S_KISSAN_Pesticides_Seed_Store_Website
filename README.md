# M/S KISSAN Pesticides & Seed Store Website

A responsive starter website for:
M/S KISSAN Pesticides & Seed Store
Village Behra Sadat, Post Morna, Tehsil Jansath, District Muzaffarnagar, Uttar Pradesh - 251316

## Included
- Home / farming hero section
- About Us
- Key Offerings
- Products with category filters
- WhatsApp product enquiry buttons
- Services
- Gallery placeholders
- Contact + enquiry form
- Mobile responsive navigation
- Generated agricultural logo concept

## Run locally
1. Keep the folder structure unchanged.
2. Open `index.html` in a browser.
3. For the best local development experience, use VS Code + Live Server.

No backend is required for this first version. The enquiry form opens WhatsApp directly.

## Product information
The sample crop/disease cards use high-level information from official Syngenta India pages. Always verify current labels, registrations, permitted crops, dosage and safety instructions before publishing or advising customers.

Important: Do not present DuPont/Syngenta branding as proof of dealership, affiliation or authorization unless the business has the appropriate authorization. Add only brands actually stocked/authorized by the shop.
